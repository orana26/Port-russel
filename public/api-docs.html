Documentation de l'API

API REST du port de plaisance Russell, développée avec Node.js, Express et MongoDB.

← Retour au tableau de bord

Authentification

  • POST /login : se connecter.
  • POST /register : créer un compte.
  • GET /logout : se déconnecter.
  • GET /me : consulter la session courante.

Catways

  • GET /catways : lister les catways.
  • GET /catways/:id : consulter un catway.
  • POST /catways : ajouter un catway.
  • PUT /catways/:id : modifier l'état d'un catway.
  • DELETE /catways/:id : supprimer un catway.

Réservations

  • GET /catways/:id/reservations : lister les réservations d'un catway.
  • GET /catways/:id/reservations/:idReservation : consulter une réservation.
  • POST /catways/:id/reservations : ajouter une réservation.
  • PUT /catways/:id/reservations/:idReservation : modifier une réservation.
  • DELETE /catways/:id/reservations/:idReservation : supprimer une réservation.

Utilisateurs

  • GET /users : lister les utilisateurs sans leurs mots de passe.
  • GET /users/:email : consulter un utilisateur par e-mail.
  • POST /users : créer un utilisateur.
  • PUT /users/:email : modifier un utilisateur.
  • DELETE /users/:email : supprimer un utilisateur.

Utilisation

Base URL en local : http://localhost:3000

Les routes de gestion nécessitent une session authentifiée. Connectez-vous d'abord pour les utiliser.

Les données envoyées par les requêtes POST et PUT sont au format JSON.
